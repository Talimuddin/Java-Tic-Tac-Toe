# 🎮 Java Tic-Tac-Toe Game

A console-based Tic-Tac-Toe game developed using **Core Java and Object-Oriented Programming (OOP)**. The game allows a human player to compete against a computer opponent.

## 📌 Project Overview

This project demonstrates Java programming fundamentals and object-oriented design through a simple, interactive Tic-Tac-Toe game. It uses an abstract player class and separate implementations for human and computer players.

## ✨ Features

* 🎯 Play Tic-Tac-Toe against a computer opponent.
* 👤 Human player moves are entered through the console.
* 🤖 Computer opponent selects valid moves randomly.
* 🧩 Uses an abstract `Player` class to define common player behavior.
* 🔄 Implements inheritance and method overriding.
* 🏆 Detects winning combinations across rows, columns, and diagonals.
* 🤝 Identifies draw conditions when no winning combination exists.

## 🛠️ Technologies Used

* **Language:** Java
* **Concepts:** Object-Oriented Programming, Abstraction, Inheritance, Polymorphism
* **Input/Output:** Java Console

## ▶️ How to Run

### Prerequisites

* Java Development Kit (JDK 21 or a compatible version)
* Command Prompt or a terminal

### Step 1: Clone the Repository

```bash
git clone https://github.com/Talimuddin/Java-Tic-Tac-Toe.git
```

### Step 2: Open the Project Folder

```bash
cd Java-Tic-Tac-Toe
```

### Step 3: Compile the Java Files

```bash
javac *.java
```

### Step 4: Run the Game

```bash
java LaunchGame
```

Follow the console instructions to play the game.

## 🧠 OOP Concepts Demonstrated

* **Abstraction:** Defines common player behavior through an abstract `Player` class.
* **Inheritance:** Implements specialized human and computer player classes.
* **Polymorphism:** Supports different player behaviors through overridden methods.
* **Encapsulation:** Organizes game data and behavior within classes.
